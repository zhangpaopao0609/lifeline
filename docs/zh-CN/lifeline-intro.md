# Lifeline：把你的 Cursor / CodeBuddy 装进口袋

[English](../lifeline-intro.md) | **简体中文**

> 本文只介绍产品功能，不涉及技术方案。用途：对外/对内介绍 Lifeline 是什么、能做什么。

## 它解决的是什么问题

在 Cursor / CodeBuddy 里用 AI 写代码的人大概都有过这样的经历：

任务发出去了，agent 开始干活。你盯着屏幕等——等它跑完、等它提问、等它要你批准一条命令。审批不来，它就卡在那里一动不动。于是你哪儿也去不了：出去吃个饭要惦记着，开个会要偷偷瞄手机，晚上回家前还得回头确认一眼。

Lifeline 想做的，就是把这根「线」接到你的手机上。

它不把你的开发搬到浏览器里，也不另起一个云端会话。你的代码、你的 IDE、你的环境，全都还在那台电脑上，一切照旧。Lifeline 只是让你能从那台电脑前**走开**——会话继续跑，需要你的时候它能找到你，你随时还能说了算。

一句话：**把守在电脑前的时间，还给你。**

## 它能做什么

### 会话不断：同一个会话，从桌面延续到手机

网页上看到的内容，就是你本机磁盘上那个会话的实时投影——不是另开的云端会话，也不是一份仓库里看不见来历的副本。你在外面看到的进度，和回来后电脑上打开的完全是同一个现场。

打开网页，当前会话的消息、回答、代码、待办一眼可见：

- 你的消息和 agent 的回复，按时间顺序排开，代码块带语言标注、可复制
- 工具调用自动归组折叠，需要看细节时再展开
- 计划卡片带 todo 进度（进行到 3/5 这样的推进）
- 当前会话在跑还是空闲，状态点实时显示

### 你说了算：不在电脑前，决定照样做

agent 停下来等你的时候，是最需要你的时候；它埋头往前跑的时候，你也随时插得上话。Lifeline 把这些都推到网页和手机上：

- **批准 / 拒绝**：shell 命令、文件修改、MCP 调用、模式切换请求……所有需要你点头的操作，网页上弹出卡片，点批准或跳过就行
- **一键全部接受**：批量遇到同类操作时，一条命令全部放行
- **回答问卷**：agent 的反问和选择题，直接在手机上选好继续
- **发新指令**：输入框就在会话下面，和你坐在电脑前打字是一回事；发送有「送达 / 已确认 / 失败可重试」三态，不玩静默丢失
- **随时叫停**：跑偏了、或只是想让它别再往下写了，点输入框旁边的停止键就行 —— 和坐在电脑前点 IDE 里那颗是同一个动作。后台在跑的那条会话也能停，不用先回电脑上切过去

一个细节：agent 的审批卡上经常有不止一个选项（Run / Always Run / Skip），网页会把每个按钮都画出来，你点哪个就是哪个。

### 装进口袋：手机竖屏也顺手

手机浏览器打开就是控制台，不用装 App：

- 顶栏一个入口切换机器、IDE、窗口、会话，打开即定位到你当前在看的那条会话
- 待办卡吸附在输入框上方，堆叠、计数，手指左右滑动切换
- 审批出来时浏览器直接弹通知：`Lifeline · 需要你批准`

### 多台电脑，同一份名单

家里一台、公司一台，都接入之后，网页上就是个机器列表：

- 一眼看清哪台在线、哪台离线；切换机器就换现场
- **离线机器也能看**：显示它最后一份镜像（只读），不会白屏、不会自动跳到别的机器上
- 离线机器可以从名单里删除；机器自己的数据一条不少，守护进程下次连上会重新出现
- 每台机器默认只归接入它的人：你登录后只看得到、管得到自己的机器

### 一个槽给 Cursor，一个槽给 CodeBuddy

同一台电脑上，Cursor 和 CodeBuddy 各占一个槽，在网页上分开显示、分开控制：

- 分别看到各自的窗口、会话、模式与模型
- 分别批准、分别发送、分别叫停，互不干扰
- 一个没连上时不会误打到另一个上

### 连控制台之外的小事也照顾到了

- **⌘K 命令面板**（桌面）：模糊搜索直达任意机器、IDE、窗口、会话、模式、模型
- **新建会话**：每个窗口分组头部都有「＋」，新会话属于窗口而不属于全局
- **窗口顺序**：可以拖拽排序，按机器和 IDE 分别记住，点会话不会让列表跳来跳去
- **接入只要两条命令**：在被控电脑上执行一条安装、一条 setup，打开浏览器登录一次即可，不需要预先装任何运行时

## 适合谁

- 习惯在本地 IDE 里开发，不想把工作流搬到浏览器或云端的人
- 经常让 AI 跑长任务，又不想一直守在电脑前的人
- 手上有不止一台机器（公司 / 家里 / 开发机）的人
- 用 CodeBuddy 或 Cursor 做主力、两者都想要的人

## 用起来是什么感觉

出门前发一个大任务，合上电脑（或者干脆让它开着）。地铁上收到通知：「需要你批准」。点开网页，看见 agent 正卡在一条命令上，看完上下文，点「批准」，把手机揣回兜里。

回到家，打开电脑——会话就停在离开时的地方，一切继续。你要接着写的代码、要验收的结果，都在原来的 IDE 里，一点没变。

**人走，线不断；回来，现场还在。**
